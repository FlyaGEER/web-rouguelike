# 🕯️ БЕЗДНА — Roguelike в браузере

Пошаговый roguelike с процедурной генерацией подземелий, предметами, этажами и боссами. Написан на чистом JavaScript: без сборки, без зависимостей, без сервера.

**▶ Играть:** https://flyageer.github.io/web-rouguelike/

## Возможности

- **Процедурные подземелья.** Каждый этаж генерируется заново из комнат и коридоров.
- **Бесконечные этажи.** В дальней комнате живёт босс. Победишь его, и откроется лестница вниз. Сложность растёт с каждым этажом.
- **5 биомов:** Подвал, Склеп, Каменные копи, Ледяной чертог, Огненная бездна.
- **5 боссов** со своими способностями и боевой рок-музыкой.
- **Предметы:** зелья, свитки, оружие, броня, золото.
- **Инвентарь, подсказки при наведении, мини-карта, полоса HP.**
- **Звук без файлов:** все эффекты и музыка синтезируются через WebAudio.
- **Seed:** один и тот же мир по ссылке, например `?seed=123`.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD / hjkl | Ход и атака (иди на врага) |
| Y U B N | Ходы по диагонали |
| `.` | Пропустить ход |
| Enter или `>` | Спуститься по лестнице |
| 1–9 | Использовать предмет из инвентаря |
| Клик по слоту | Использовать предмет |
| Правый клик по слоту | Выбросить предмет |
| M | Звук вкл/выкл |
| R | Начать заново |

Наведи мышь на врага, предмет или лестницу, чтобы увидеть подсказку.

## Боссы

Красные клетки на полу показывают, куда босс ударит на следующем ходу: успей с них сойти. Ниже 50% HP босс впадает в ярость, бьёт сильнее, а музыка ускоряется.

| Босс | Музыка | Способности |
|---|---|---|
| Король Крыс | панк | призыв крыс, таран |
| Некромант | дум | призыв скелетов, кража жизни, заряд |
| Каменный Голем | стоунер | удар по кругу, таран |
| Лич | метал | телепорт, заряд, нова, призыв призраков |
| Дракон Бездны | трэш | огненное дыхание, нова, таран, удар по кругу |

После пятого босса биомы и боссы идут по кругу, но становятся сильнее.

## Запуск

Откройте `index.html` в браузере. Больше ничего не нужно.

Звук включается после первого нажатия клавиши или клика (так требуют браузеры).

## Структура проекта

```
├── index.html
├── css/style.css
└── js/
    ├── main.js              ввод, HUD, тултипы, игровой цикл
    ├── core/
    │   ├── rng.js           ГСЧ с seed
    │   ├── audio.js         звуковые эффекты
    │   └── music.js         боевая музыка боссов
    ├── data/
    │   ├── monsters.js      обычные враги
    │   ├── items.js         предметы
    │   └── bosses.js        боссы и биомы
    ├── world/
    │   ├── dungeon.js       генерация уровня
    │   └── fov.js           поле зрения
    ├── game/
    │   ├── game.js          ходы, бой, инвентарь, этажи
    │   └── boss.js          способности и ИИ боссов
    └── render/
        ├── renderer.js      отрисовка на canvas
        ├── sprites.js       пиксельные спрайты 8×8
        └── minimap.js       мини-карта
```

Порядок подключения скриптов в `index.html` важен: каждый файл использует то, что определено до него.

## Как расширять

- **Новый враг:** добавьте объект в `js/data/monsters.js` и спрайт с тем же символом в `js/render/sprites.js`.
- **Новый предмет:** добавьте ветку в `makeItem` и `describe` (`js/data/items.js`), а эффект в `S.use` (`js/game/game.js`).
- **Новый босс:** допишите объект в `G.BOSSES` (`js/data/bosses.js`), выберите тему музыки и набор способностей. Спрайт добавьте в `sprites.js`.
- **Новая способность босса:** добавьте функцию в `ABIL` (`js/game/boss.js`).
- **Новая тема музыки:** добавьте рифф и ритм в `THEMES` (`js/core/music.js`).
- **Новый биом:** добавьте цвета в `G.BIOMES` (`js/data/bosses.js`).
- **Другой тип уровней** (пещеры, BSP): замените генератор в `js/world/dungeon.js`.
